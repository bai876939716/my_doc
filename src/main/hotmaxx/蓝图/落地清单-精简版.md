## 一、⭐ 必须落地（19 项 · MVP 端到端）

> 已按依赖排序：1~4 后端地基 → 5~6 能力 → 7~9 体验闭环。

| # | 做什么 | 包含（对应全量编号） |
|---|---|---|
| 1 | **状态机引擎**：字段级状态 + 转移表配置化；LLM 只做识别不做决策；含主动退出 / 草稿恢复 | M1.1 M1.5 |
| 2 | **解析 + 校验**：一句话填多字段（描述→现象/时间/影响范围）；枚举白名单、手机号、100 字上限，不通过生成澄清话术 | M1.2 M1.3 |
| 3 | **对话边界 + 防注入**：意图分诊（补信息/改字段/问进度/闲聊/越权/注入）一律拉回；连续 2~3 轮失败降级卡片或回表单（FA.md 原则 8） | M9.4 基础 |
| 4 | **明道云对接**：单账号服务端收口、order_key 幂等、10 字段映射；门店/报修人员/报修日期 3 字段自动带出（员工档案 + 门店主数据） | M2.1 M2.2 M2.3 |
| 5 | **4 个 MCP 工具**：员工/门店信息、枚举字典、提交报修单（create_repair_order）、查报修记录（按用户过滤）；工具注册/参数校验/超时 | M3.1 M3.2 |
| 6 | **模型接入**：主 LLM（选型 11.5 拍板）+ 最小网关（超时/重试/失败降级，不裸调） | M4.1 M4.2 |
| 7 | **会话与草稿**：一会话一单、Redis 快照先存再推、7 天草稿、断点续填（重进复用活跃会话） | M5.2 M6.1 |
| 8 | **入口与鉴权**：表单页顶部「AI 智能填报」入口；App 登录态；按门店隔离 + 越权拦截 | M5.1 M9.1 基础 |
| 9 | **前端三件套**：对话页（自由描述 Top3 / 高频卡片直锁 双路径）、预填确认单（点哪改哪、人工点提交才入库）、退出三选项 + 提交成功直达记录页（列表/详情按用户过滤） | M7.1 M7.2 M1.4 |
