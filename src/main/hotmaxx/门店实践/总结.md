# 好特卖门店调研总结

> 2026-10-31 · 门店实地走访 + 店长访谈

## 一、门店基本情况

- **营业时间**：10:00–22:00，跟随商场
- **高峰期**：周日 12:00–13:30、18:00–20:30；周末 11:30–14:00、17:30–20:30（具体可结合收银频次曲线验证）

## 二、岗位职责

- **白班**：收银、拉面（排面整理）、上货、叫卖、巡场、标签置换
- **夜班（22:00–05:00）**：上货、取货、验收等

## 三、排班逻辑

排班操作需要考虑：

1. **工时**：保证员工全月日均工时达标
2. **忙闲配置**：门店闲时、忙时的人员配比
3. **员工诉求**：请假等个人需求协调
4. **用餐错峰**：⚠️ 暗逻辑——系统未体现，靠店长口头要求，避免用餐撞上高峰导致人手不足
5. **常规班模式**：10:00–20:00 / 12:00–22:00

## 四、店长关注点

- **营收是否达标**：直接影响绩效
- **店务分**：参考维度有饱满、陈列、标签等

## 五、货物流转

1. **店长 ↔ 区总**：沟通确定箱数（需考虑门店仓储能力）和时间点
2. **配货组**：协调生成配货单
3. **仓储转运**：与夜班交接 → 验收 → 上货

## 六、待深入

- **货物摆放规则**：目前只有硬性约束（几行几列、区域类型），具体摆放取决于员工经验
- **系统槽点**：店长暂无反馈
