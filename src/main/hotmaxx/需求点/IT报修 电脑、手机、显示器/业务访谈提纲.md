# 门店电脑报修流程优化 · 业务访谈提纲

> 版本 v0.1 · 2026-11-24 · 用于现状调查与需求摸底

## 一、访谈说明

目的：摸清门店电脑报修流程的现状、各角色的真实痛点与期望，为后续流程优化和产品方案设计提供事实依据。

1. 每场访谈建议 30–45 分钟，一对一进行，避免上下级同场导致信息失真。
2. 核心原则：多问「最近一次具体案例」、多让受访者现场演示，少问抽象观点。观点会美化，行为不会。
3. 如需录音，必须事先征得受访者同意；记录中涉及具体人员的负面评价只作内部参考。
4. 访谈顺序建议：先运维（流程中枢，建立全貌）→ 门店员工（发起方）→ 供应商（处理方）→ 管理层（决策方，最后对齐目标）。

> 提示：每份提纲不必问完，根据现场情况取舍。**加粗显示的问题**建议优先保证问到。

## 二、通用开场（所有角色，约 5 分钟）

1. **您的角色和日常工作内容是什么？和电脑报修这件事的交集是什么？**
2. 最近一次接触报修流程是什么时候？当时发生了什么，结果如何？
3. 如果用一句话形容现在的报修流程，您会怎么说？

## 三、门店员工（报修发起方）

### 主题 A：报修发起

1. **电脑出问题时，您怎么知道该走报修流程？第一次是怎么学会的？**
2. 请现场演示一次报修填报（拿出表单实际走一遍）——访谈人记录卡住、犹豫、乱填的位置。
3. 表单里哪些信息您经常不确定怎么填？（故障类型、设备编号、门店编号等）
4. 描述故障时，觉得说不清楚的情况多吗？一般怎么补充——拍照、打电话还是找人代填？

### 主题 B：等待与解决

1. **提交之后一般多久有人响应？您怎么知道处理进度？需要催吗？催谁、怎么催？**
2. 从报修到修好，通常要多久？最快和最慢的一次分别多久？
3. 收银机等关键设备故障影响营业时，你们有没有绕过正常流程的加急做法？
4. 修完后有没人跟您确认修好了？同样的问题反复出现的情况多吗？

### 主题 C：感受与期望

1. 现在流程里最让您烦恼的三件事是什么？
2. 如果只能改一件事，您最希望改什么？为什么是它？

## 四、运维（受理与调度方）

### 主题 A：受理

1. **表单提交后经过哪些环节到达您手上？您用什么工具查看（表格、群消息、系统）？**
2. 最常遇到的信息不全是什么？为补齐一次信息要花多少时间、通过什么渠道？
3. 有没有重复报修、一单多报的情况？怎么识别和合并？

### 主题 B：分派供应商

1. **「联系对应的供应商」中的对应关系是怎么定的——按设备品牌、区域、故障类型还是合同？有成文规则吗？**
2. 目前合作的供应商有几家？各家的响应速度、能力、服务范围差异如何？
3. 派单用什么方式（电话/微信/邮件）？怎么确认供应商已经接单？
4. 有没有想更换或淘汰某家供应商的时候？当时怎么处理的？

### 主题 C：跟踪与闭环

1. **您怎么知道一单已经修好？验收谁来做，门店需要确认吗？**
2. 维修费用怎么结算（按次/包年/框架协议）？对账的工作量大吗？
3. 每月大概多少单？有没有明显的高峰期？故障类型的大致分布？

### 主题 D：数据与工具

1. **现在的记录方式能支撑统计分析吗？您最想看但拿不到的数据是什么？**
2. 公司有没有资产台账、工单系统或 IT 监控？如果有，为什么当前流程没用起来？
3. 您每天/每周在报修这件事上花多少时间？其中纯「中转传话」占多少？

## 五、供应商（处理方）

1. **您从谁、以什么方式接到报修？收到的信息通常够用吗？最常缺什么？**
2. 合同里有书面 SLA（如 4 小时响应、次日到店）吗？实际能做到吗？做不到的时候怎么处理？
3. 接到的报修里最常见的故障类型是什么？其中哪些其实门店自己就能解决？
4. 与门店、与运维的沟通中，最大的摩擦点分别是什么？
5. 结算流程顺畅吗？一般多久回款？对账依据是什么？
6. 如果公司提供一个系统让你们在线接单、反馈进度、上传凭证，您觉得最有用的功能会是什么？最不希望增加的负担是什么？

## 六、管理层（决策方）

1. **这个流程目前最影响业务的指标是什么——门店停机时长、维修成本、还是门店满意度？**
2. 目前的年维修成本大概什么量级？您觉得偏高吗？主要花在哪些地方？
3. 对这个优化项目，您的期望和边界是什么（预算、时间、能动的系统范围）？
4. **项目做到什么程度算成功？三个月后、一年后分别希望看到什么？**
5. 有没有必须保留的约束——现有供应商合同、合规要求、组织汇报关系？
6. 除了电脑，门店其他设备（打印机、收银外设、网络）是否也走同一流程？要不要一并考虑？

## 七、通用收尾（所有角色）

1. 还有什么我没问到、但您觉得很重要的事吗？
2. 您还建议我去找谁聊聊？（滚雪球抽样，尤其是一线的实际操作者）
3. 后续整理中如果有疑问，方便再联系您确认吗？
