# 门店电脑报修 · 现状流程调查模板（As-Is）

> 访谈前准备的调查工具（2026-11-24）。已知的现状已整理进产品方案的 `01-现状流程图.puml`，本模板留作访谈时逐项核对、补空用。

调查模板图：[diagrams/00-现状流程图-调查模板.puml](产品/diagrams/00-现状流程图-调查模板.puml)

## 怎么用

1. 图里每个节点旁的 **【__】** 是待填的事实，访谈或现场观察后补上；耗时尽量给"典型值 + 最差值"。
2. **⚠** 标注是预设的常见卡点，访谈中没发现就直接删掉该标注。
3. 右侧黄色备注框是需要额外确认的"表单之外"的路径（群里催办、绕过流程的加急等），重点确认是否存在、频率多高。
4. 调查完成后，把确认的路径保留，被绕过的环节在节点上注明"名存实亡"。

配套的访谈问题见 [业务访谈提纲.md](业务访谈提纲.md)。
