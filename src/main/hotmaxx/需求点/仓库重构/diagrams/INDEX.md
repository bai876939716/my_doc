## 渲染命令

仓库目前没有渲染工具链，图源靠编辑器插件本地预览。需要批量出图时用：

```bash
plantuml -tsvg src/main/hotmaxx/需求点/仓库重构/diagrams/*.puml   # 或 docker run --rm -v $PWD:/p plantuml/plantuml
```

2026-11-27 用 PlantUML 1.2022.7 对六张图做过本地渲染，语法都通过。03、05、06 的渲染结果内嵌在 `03-系统现状/服务介绍.html` 里（单文件页面，图是渲染后贴进去的，页面上「图源」链接指向本目录的 puml）。**改了这三张图的图源，要重新渲染并重新内嵌，否则页面里的图会滞后于图源。** 01、02、04 的渲染件没有提交。

## 维护规则（同一变更内）

访谈确认了新的环节，或流程有改动，02-业务现状/业务内容.md 的步骤表、对应的图源（01、02）、本索引行要在同一次改动里一起更新。总图按单据分段，某张单据变了只改它那一段，其余段不动。

03 按业务分段，某条业务变了只改它那一段；服务改名、合并、新增时，图里的参与方、05 的方块和服务介绍.html 的「逐个服务」一起改。05 只画主链路，新增一条主要的调用、或某个服务换了层，要改图；06 是一条通用主线，主线多一步或少一步（比如多了一道预占、回传的落单方式变了）要改图，同时改页面里那一段说明。04 只画主链路，加表、改关联字段时，和 03-系统现状/表关系.md 的第六、七节一起改。
