## 渲染命令

仓库目前没有渲染工具链，图源靠编辑器插件本地预览。需要批量出图时用：

```bash
plantuml -tsvg src/main/hotmaxx/需求点/仓库重构/diagrams/*.puml   # 或 docker run --rm -v $PWD:/p plantuml/plantuml
```

## 维护规则（同一变更内）

访谈确认了新的环节，或流程有改动，业务内容.md 的步骤表、对应的图源、本索引行要在同一次改动里一起更新。总图按单据分段，某张单据变了只改它那一段，其余段不动。

服务交互图按业务分段，某条业务变了只改它那一段，同时改服务介绍.md 的第四节；服务改名、合并、新增时，图里的参与方和服务介绍.md 第三节一起改。核心表关系图只画主链路，加表、改关联字段时，和表关系.md 的第六、七节一起改。

图源语法错误只有渲染时才暴露，改完先本地渲染一次再提交。
