# 接口文档 · H5 ↔ Agent 服务（报修技能包）

> **版本**：v2.1（2026-11-05 · design/5 报修版：用户 type 6 种 / 服务端 type 10 种，URL 保留技能包参数位）｜**协议变更规则**：本文档是 H5 ↔ Agent 消息契约的唯一真值，新增/修改字段或 type 须前后端双方确认后同步本文档；type 只描述「手势/消息种类」，与前端组件实现解耦。
> 兼容性预留：后续技能包（报销等）新增 type 遵循 v1 内兼容原则（只增不改），届时随该技能包评审补充本文档。
> 上线前 TODO：真实域名、token 签发方式（复用 App 登录态）。

## 0. 通用约定

| 项 | 约定 |
|---|---|
| Base URL | `https://{gateway-host}/agent/repair/v1`（经公司网关转发，按 `/agent/**` 路由到 Agent 服务，是否 StripPrefix 与平台组确认） |
| URL 规范 | 服务前缀 `/agent` + 业务二级（技能包）`repair` + 版本 `/v1`——技能包独立升版（报销届时为 `/agent/expense/v1`），仅消息协议破坏性变更才升版本号 |
| 内容类型 | 请求/响应 `application/json; charset=utf-8`；SSE 响应 `text/event-stream` |
| 鉴权 | `Authorization: Bearer <token>`（App 登录态，网关校验后注入 `HTM-HEADER`） |
| 时间格式 | `yyyy-MM-dd'T'HH:mm:ss+08:00` |
| 并发 | 同一会话不做多端并发控制（后写覆盖，已知简化）；防重复提交由服务端 order_key（= 会话 ID）幂等保证 |
| 手机号 | 任何出参不出现完整手机号，一律掩码（`138****1234`） |

**错误响应体**（所有非 2xx 统一结构）：

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 业务错误码，见 §3 |
| message | string | 人话描述，前端可直接 toast |

## 1. 接口总览

| # | 接口 | 方法 | 用途 |
|---|---|---|---|
| 1 | `/agent/repair/v1/sessions` | POST | 建会话 / 恢复入口 |
| 2 | `/agent/repair/v1/sessions/{id}/messages` | POST | 用户消息（响应 = SSE 流） |
| 3 | `/agent/repair/v1/sessions/{id}/upload` | POST | 附件上传（multipart） |
| 4 | `/agent/repair/v1/sessions/{id}` | GET | 会话内刷新 / SSE 断线重连 |
| 5 | `/agent/repair/v1/sessions/{id}/submit` | POST | 确认提交 |
| 6 | `/agent/repair/v1/sessions/{id}/exit` | POST | 主动退出 |

## 2. 接口明细

### 2.1 建会话 / 恢复入口 —— `POST /agent/repair/v1/sessions`

**请求**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| store_no | string | 否 | 门店编号；默认取登录人绑定门店，督导多店时显式指定 |

**响应 200**：

| 字段 | 类型 | 说明 |
|---|---|---|
| session_id | string | 会话 ID（`rp_` 前缀），后续接口路径参数 |
| is_resumed | boolean | true=复用了活跃会话（前端弹「继续上次报修」卡片） |
| context | object | 系统带出字段：`store`(string) / `reporter`(string) / `date`(string) / `phone_masked`(string) |
| messages | array | 首屏消息序列，**按 seq 顺序渲染**；元素结构见 §2.2 服务端消息 |

```json
{ "session_id": "rp_9f3k2m", "is_resumed": false,
  "context": { "store": "11522 安徽商之都OK店", "reporter": "白云翔", "date": "2026-11-05", "phone_masked": "138****1234" },
  "messages": [
    { "seq": 1, "type": "status_bar", "data": { "store": "11522 安徽商之都OK店", "reporter": "白云翔", "phone_masked": "138****1234" } },
    { "seq": 2, "type": "text", "data": { "content": "白云翔你好！直接说哪儿坏了就行，比如「冷柜不制冷了，今天早上开始的」" } },
    { "seq": 3, "type": "quick_cards", "data": { "cards": [ { "id": "c_cool", "icon": "❄️", "title": "冷柜/空调不制冷" } ] } }
  ] }
```

### 2.2 发消息 —— `POST /agent/repair/v1/sessions/{id}/messages`（响应 = SSE 流）

**请求公共字段**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| type | string | 是 | 手势类型，六种（见下）；只有 `text` 走 LLM，其余为结构化事件 |
| （其余字段） | — | — | 按 type 见下表 |

**用户消息 type 6 种**（`submit` 走独立接口 §2.5，不经 messages）：

| type | 附加字段 | 类型 | 说明 |
|---|---|---|---|
| `text` | content | string ≤500 | 一切打字：描述 / 补充 / 改字段（语音输入经前端 ASR 回填后同此 type，预留 source=voice 埋点维度） |
| `card` | card_id | string | 高频卡片 ID（类别直锁，免类别免描述） |
| `enum_pick` | field / value | string ×2 | 枚举点选值（必须字典内）；confirm 态收到 = 确认单重选类别，触发照片/描述联动重校验 |
| `seg_pick` | field / value | string ×2 | field ∈ `expect_visit`｜`impact_business`；同一手势复用 |
| `upload_done` | media_ids | array\<string\> | 上传完成通知（先调 §2.3 拿 media_id） |
| `phone` | use_default 或 phone | boolean / string | 二选一：用本人号码 / 提交新号码（11 位正则校验） |

**SSE 事件规范**：

| event | data 结构 | 说明 |
|---|---|---|
| typing | `{}` | 收到请求立即下发，前端显示"输入中" |
| message | `{ "seq": int, "type": string, "data": object }` | 0..n 条；data 按 type 见下表 |
| done | `{ "state": string, "focus": string? }` | 终止事件；state/focus 见 §4 枚举 |
| （注释行） | `: ping` | 每 15s 一条心跳，防中间层掐连接 |

**服务端消息 type 10 种（message.data 结构）**：

| type | data 字段 | 类型 | 说明 |
|---|---|---|---|
| `status_bar` | store / reporter / phone_masked | string ×3 | 顶部状态条 |
| `text` | content | string | 对话气泡（模板话术） |
| `quick_cards` | cards[].id / icon / title | string ×3 | 高频卡片墙 |
| `enum_card` | field / mode / options[] / preselect | string ×4 | mode ∈ `top3`｜`full`；preselect=预选下标（-1 无）；**仅限点选** |
| `photo_guide` | need_count / tips[].text / tips[].level / warning | int / string / `info`｜`warn` / string? | 拍摄清单；warning 非空时红色警示（购物袋拍袋底供应商标识） |
| `system_tip` | content / level | string / `info`｜`warn`｜`error` | 系统提示条（非对话语气） |
| `seg_card` | field / question / options[].value / options[].label | string ×4 | 二选一卡（期望上门 / 影响营业复用） |
| `phone_confirm` | phone_masked / use_default | string / boolean | 电话确认卡 |
| `confirm_card` | groups[].group_name / groups[].items[].field·label·value·editable·source / missing[] | — / string ×5 / array\<string\> | 10 字段确认单；source ∈ `system_default`｜`ai_filled`｜`user_edited`；missing=缺失字段提示 |
| `result` | order_no / status / tip | string ×3 | 结果卡（单号 / 状态 / 提示文案） |

### 2.3 上传附件 —— `POST /agent/repair/v1/sessions/{id}/upload`

**请求**：`multipart/form-data`，字段 `files[]`（image/* 或 video/*，单文件 ≤10MB，单会话 ≤5 个）。

**响应 200**：

| 字段 | 类型 | 说明 |
|---|---|---|
| media_ids | array\<string\> | 附件 ID，供 `upload_done` 消息引用 |
| urls | array\<string\> | 预览地址（OSS 临时链接） |

### 2.4 恢复会话 —— `GET /agent/repair/v1/sessions/{id}`

**响应 200**：结构同 §2.1，另增：

| 字段 | 类型 | 说明 |
|---|---|---|
| state | string | 当前图状态（§4 枚举），前端据此渲染当前步骤 |
| focus | string? | collecting 态下当前正在采集的槽位名 |
| collected | object | 已采集槽位（含 source），确认单/回显用 |

404 = 会话不存在 / 已过期 / 已废弃 → 前端静默开新会话。

### 2.5 提交 —— `POST /agent/repair/v1/sessions/{id}/submit`（仅 confirm 态接受）

**请求**：无请求参数（服务端以会话快照为准，order_key = 会话 ID）。服务端行为 = 恢复 confirm 节点的 interrupt 挂起（`Command(resume)`）。

**响应 200**：

| 字段 | 类型 | 说明 |
|---|---|---|
| order_no | string | 报修单号（明道云返回） |
| status | string | 工单状态（如「已提交 / 待派单」） |

服务端流程：10 字段必填校验（卡片路径描述自动补默认值）→ `create_repair_order`（order_key 幂等）→ 删检查点与活跃索引 → 终态归档 MySQL。

### 2.6 主动退出 —— `POST /agent/repair/v1/sessions/{id}/exit`

**请求**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| mode | string | 是 | `keep`=保存草稿（7 天可续）｜`abandon`=放弃本次报修 |

**响应 200**：

| 字段 | 类型 | 说明 |
|---|---|---|
| result | string | 固定 `ok` |
| draft_expired_at | string | keep 时返回，草稿过期时间；abandon 不返回 |

## 3. 错误码

| code | HTTP | 场景 | 前端行为 |
|---|---|---|---|
| 40101 | 401 | token 无效/过期 | 引导重新登录 |
| 40401 | 404 | 会话不存在/过期/废弃 | 静默开新会话 |
| 42201 | 422 | 提交字段校验失败 | 收 confirm_card，高亮 missing 字段 |
| 42901 | 429 | 当日 LLM 配额用尽 | 收 system_tip，降级卡片向导 |
| 50301 | 503 | LLM 不可用 / 引擎运行时异常 | 降级卡片向导 / 引导回表单 |
| 50302 ❗ | 503 | 明道云提交失败-已转待重试（**待评审确认后正式启用**） | 提示稍后自动重试 + 客服兜底 |

## 4. 枚举字典

**图状态 state（5）**：`collecting`（采集进行中）/ `confirm`（确认单挂起，等 submit）/ `done`（提交成功）/ `exited`（主动退出）/ `fallback`（降级卡片向导）

**focus 槽位名（报修）**：`category` · `detail` · `photos` · `expect_visit` · `impact_business` · `phone`

**seg_pick.field（2）**：`expect_visit` ｜ `impact_business`

**enum_card.mode（2）**：`top3`（AI 候选）｜ `full`（FALLBACK 全量）

**槽位 source（3）**：`system_default` ｜ `ai_filled` ｜ `user_edited`

## 5. 场景示例

> 按 H5 真实交互时序串联的完整报文流。通用约定：`seq` 全会话单调递增；SSE 三事件 `typing / message / done`，每 15s 一条 `: ping` 心跳（注释行，前端忽略）。

### 5.1 自由描述（主路径全流程）

**① 建会话**：请求 `{"store_no": null}`，响应同 §2.1 示例。

**② 自由描述（全流程唯一 LLM 调用点）**

```json
{ "type": "text", "content": "店里的冷藏风幕柜不制冷了，柜内温度显示15度，今天早上开始的，里面的鲜奶不敢卖只好全下架了。" }
```

响应 = SSE 流（`text/event-stream` 原文）：

```
event: typing
data: {}

event: message
data: {"seq":4,"type":"text","data":{"content":"听下来了。我认出的类别如下——怕报错被驳回，点一下确认（不对就选别的）："}}

event: message
data: {"seq":5,"type":"enum_card","data":{"field":"category","mode":"top3","options":["工程类 - 制冷设备/冷柜","工程类 - 暖通/空调","特别紧急 - 影响营业的紧急故障"],"preselect":0}}

event: done
data: {"state":"collecting","focus":"category"}
```

> `preselect: 0` = AI 首位预选仅影响卡片顺序，**必须点选**才入槽（enum_first_pick 埋点在此触发）。

**③ 点选类别 → 拍照引导**

```json
{ "type": "enum_pick", "field": "category", "value": "工程类 - 制冷设备/冷柜" }
```

```
event: message
data: {"seq":6,"type":"text","data":{"content":"类别登记好了。麻烦拍两张现场照片：设备整体 + 问题部位，维修师傅好提前判断。"}}

event: message
data: {"seq":7,"type":"photo_guide","data":{"need_count":2,"tips":[{"text":"设备整体一张","level":"info"},{"text":"问题部位特写一张","level":"info"}],"warning":null}}

event: done
data: {"state":"collecting","focus":"photos"}
```

**④ 上传照片 `POST .../upload`（multipart）→ `upload_done`**

```json
{ "type": "upload_done", "media_ids": ["m_001", "m_002"] }
```

```
event: message
data: {"seq":9,"type":"seg_card","data":{"field":"expect_visit","question":"期望上门","options":[{"value":"维修人员尽快上门","label":"🔧 维修人员尽快上门"},{"value":"可等待安排","label":"🗓 可等待安排"}]}}

event: done
data: {"state":"collecting","focus":"expect_visit"}
```

**⑤ 期望上门 → 影响营业（带 AI 预判）→ 联系电话**：`seg_pick` ×2、`phone` 逐一下发，`focus` 依次 `impact_business` → `phone`。

**⑥ 确认单 → 提交**

```
event: message
data: {"seq":12,"type":"confirm_card","data":{"groups":[
  {"group_name":"基础信息（系统带出）","items":[
    {"field":"store","label":"门店名称","value":"11522 安徽商之都OK店","editable":true,"source":"system_default"},
    {"field":"reporter","label":"报修人员","value":"白云翔","editable":true,"source":"system_default"},
    {"field":"date","label":"报修日期","value":"2026-11-05","editable":true,"source":"system_default"}]},
  {"group_name":"报修内容（AI 采集整理）","items":[
    {"field":"category","label":"报修类别","value":"工程类 - 制冷设备/冷柜","editable":true,"source":"user_edited"},
    {"field":"detail","label":"描述具体故障","value":"故障现象：冷藏风幕柜不制冷，柜内温度 15℃；发生时间：今天早上开始；影响范围：柜内鲜奶已下架，暂无法销售","editable":true,"source":"ai_filled"},
    {"field":"photos","label":"现场照片","value":"2 张","editable":true,"source":"user_edited"},
    {"field":"expect_visit","label":"期望上门","value":"维修人员尽快上门","editable":true,"source":"user_edited"},
    {"field":"impact_business","label":"影响营业","value":"是","editable":true,"source":"user_edited"},
    {"field":"phone","label":"联系电话","value":"138****1234","editable":true,"source":"system_default"},
    {"field":"expect_process","label":"期望处理（选填）","value":"","editable":true,"source":"system_default"}]}
],"missing":[]}}

event: done
data: {"state":"confirm"}
```

`POST /agent/repair/v1/sessions/rp_9f3k2m/submit`（无请求参数，order_key=会话 ID）：

```json
{ "order_no": "BX-20261105-0007", "status": "已提交 / 待派单" }
```

前端渲染 result 卡（单号 + 「查看报修记录」跳已有记录页）；检查点清除、会话归档 MySQL。

### 5.2 高频卡片（0 次 LLM，只列差异）

```json
{ "type": "card", "card_id": "c_cool" }
```

直接下发 `photo_guide`（`focus: photos`）；购物袋类差异（`c_bag`）`warning` 非空触发红色警示：

```
event: message
data: {"seq":5,"type":"photo_guide","data":{"need_count":3,"tips":[{"text":"问题部位","level":"info"},{"text":"袋底供应商标识（必拍）","level":"warn"}],"warning":"购物袋类报修须拍袋底供应商标识，否则会被驳回"}}
```

卡片路径确认单差异：`detail` 为空自动补默认值 `"制冷设备/冷柜，详见现场照片"`（source `system_default`）。

### 5.3 断点恢复（杀 App 后重进 / 主动退出 keep 后重进）

统一入口 `POST /agent/repair/v1/sessions`（不带本地 session_id，恢复不依赖前端缓存）：

```json
{
  "session_id": "rp_9f3k2m",
  "is_resumed": true,
  "context": { "store": "11522 安徽商之都OK店", "reporter": "白云翔", "date": "2026-11-05", "phone_masked": "138****1234" },
  "messages": [
    { "seq": 12, "type": "confirm_card", "data": { "...": "会话内已产生的消息按 seq 重放" } },
    { "seq": 13, "type": "text", "data": { "content": "检测到未完成的报修（工程类 - 制冷设备/冷柜），继续上次填写？" } }
  ]
}
```

前端弹「继续上次报修」卡片；用户确认后按快照渲染界面。

会话内刷新 / SSE 断线重连：`GET .../rp_9f3k2m`——结构同上，另含 `state` / `focus` / `collected`；404（code 40401）时前端静默开新会话：

```json
{ "state": "collecting", "focus": "photos", "collected": { "category": "工程类 - 制冷设备/冷柜", "photos": ["m_001"] } }
```

### 5.4 随时可改（任意时刻打字，焦点不变）

在 `focus: expect_visit` 时打字改电话：

```json
{ "type": "text", "content": "电话换成店长的 13900005678" }
```

```
event: typing
data: {}

event: message
data: {"seq":13,"type":"text","data":{"content":"已把联系电话更新为「139****5678」，继续当前的步骤就行。"}}

event: done
data: {"state":"collecting","focus":"expect_visit"}
```

> `done.focus` 与改前相同——改普通字段原地覆盖槽位、**议程不变**；检查点已自动更新。

confirm 态重选类别（例外，联动失效）：发 `{"type":"enum_pick","field":"category","value":"工程类 - 照明/招牌"}` → 照片/描述钩子失效 → `done` 返回 `{"state":"collecting","focus":"photos"}`。

### 5.5 异常与降级

**提交缺字段（422）**：

```json
HTTP/1.1 422
{ "code": 42201, "message": "还有 1 项没填：现场照片" }
```

**会话 LLM 次数超限（429 → 降级卡片向导）**——打字消息仍返回 SSE，但不再调 LLM：

```
event: message
data: {"seq":14,"type":"system_tip","data":{"content":"AI 手速有点慢，先用卡片点选填，一样能交单","level":"warn"}}

event: message
data: {"seq":15,"type":"enum_card","data":{"field":"category","mode":"full","options":["（全量类别列表，来自字典）"],"preselect":-1}}

event: done
data: {"state":"fallback"}
```

**LLM 服务不可用 / 引擎运行时异常（503）**：

```json
HTTP/1.1 503
{ "code": 50301, "message": "AI 暂时不可用，已切换为卡片填报" }
```

**明道云提交失败（待发表机制）**——50302（❗待评审确认）：

```json
HTTP/1.1 503
{ "code": 50302, "message": "提交暂时失败，已记录自动重试；紧急请联系客服 400-xxx-xxxx" }
```

### 5.6 主动退出

keep：`{ "mode": "keep" }` → `200 { "result": "ok", "draft_expired_at": "2026-11-12T09:41:00+08:00" }`；abandon 后 GET 返回 404/40401，前端静默开新会话。

### 5.7 前端联调自查清单

| 检查项 | 口径 |
|---|---|
| seq 连续性 | 每条 message.seq 严格递增；重连后从快照重放不重不漏 |
