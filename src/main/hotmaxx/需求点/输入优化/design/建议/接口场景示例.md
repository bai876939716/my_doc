## 场景 1 · 分支A 自由描述（主路径全流程）

### 1.1 建会话 —— `POST /api/sessions`

```json
{ "store_no": null }
```

响应 200（新会话）：

```json

  "is_resumed": false,
  "context": { "store": "11522 安徽商之都OK店", "reporter": "白云翔", "date": "2026-11-04", "phone_masked": "138****1234" },
  "messages": [
    { "seq": 1, "type": "status_bar", "data": { "store": "11522 安徽商之都OK店", "reporter": "白云翔", "phone_masked": "138****1234" } },

    { "seq": 3, "type": "quick_cards", "data": { "cards": [
```

### 1.2 自由描述（全流程唯一 LLM 调用点）—— `POST /api/sessions/rp_9f3k2m/messages`

```json
{ "type": "text", "content": "店里的冷藏风幕柜不制冷了，柜内温度显示15度，今天早上开始的，里面的鲜奶不敢卖只好全下架了。" }
```

响应 = SSE 流（`text/event-stream` 原文）：

```
event: typing
data: {}

event: message
data: {"seq":4,"type":"text","data":{"content":"听下来了。我认出的类别如下——怕报错被驳回，点一下确认（不对就选别的）："}}

event: message
data: {"seq":5,"type":"enum_card","data":{"mode":"top3","options":["工程类 - 制冷设备/冷柜","工程类 - 暖通/空调","特别紧急 - 影响营业的紧急故障"],"preselect":0}}

event: done
data: {"state":"A_ENUM"}
```

> `preselect: 0` = AI 首位预选仅影响卡片顺序，**必须点选**才入槽（enum_first_pick 埋点在此触发）。

### 1.3 点选类别 → 拍照引导

```json
{ "type": "enum_pick", "value": "工程类 - 制冷设备/冷柜" }
```

```
event: message
data: {"seq":6,"type":"text","data":{"content":"类别登记好了。麻烦拍两张现场照片：设备整体 + 问题部位，维修师傅好提前判断。"}}

event: message
data: {"seq":7,"type":"photo_guide","data":{"need_count":2,"tips":[{"text":"设备整体一张","level":"info"},{"text":"问题部位特写一张","level":"info"}],"warning":null}}

event: done
data: {"state":"PHOTO"}
```

### 1.4 上传照片 —— `POST /api/sessions/rp_9f3k2m/upload`（multipart）

```
files[] = 冷藏柜整体.jpg（image/jpeg, 2.1MB）
files[] = 问题部位.jpg（image/jpeg, 1.8MB）
```

```json
{ "media_ids": ["m_001", "m_002"], "urls": ["https://oss.../m_001.jpg", "https://oss.../m_002.jpg"] }
```

通知入槽：

```json
{ "type": "upload_done", "media_ids": ["m_001", "m_002"] }
```

```
event: message
data: {"seq":8,"type":"text","data":{"content":"照片收到。期望上门怎么安排？"}}

event: message
data: {"seq":9,"type":"seg_card","data":{"field":"expect_visit","question":"期望上门","options":[{"value":"维修人员尽快上门","label":"🔧 维修人员尽快上门"},{"value":"可等待安排","label":"🗓 可等待安排"}]}}

event: done
data: {"state":"EXPECT"}
```

### 1.5 期望上门 → 影响营业（带 AI 预判）→ 联系电话

```json
{ "type": "seg_pick", "field": "expect_visit", "value": "维修人员尽快上门" }
```

```
event: message
data: {"seq":10,"type":"seg_card","data":{"field":"impact_business","question":"这故障影响做生意吗？你提到鲜奶下架卖不了，我猜是影响了，对吗？","options":[{"value":"是","label":"✅ 影响"},{"value":"否","label":"不影响"}]}}

event: done
data: {"state":"IMPACT"}
```

```json
{ "type": "seg_pick", "field": "impact_business", "value": "是" }
```

```
event: message
data: {"seq":11,"type":"phone_confirm","data":{"phone_masked":"138****1234","use_default":true}}

event: done
data: {"state":"PHONE"}
```

```json
{ "type": "phone", "use_default": true }
```

### 1.6 确认单 → 提交

```
  {"group_name":"基础信息（系统带出）","items":[
    {"field":"store","label":"门店名称","value":"11522 安徽商之都OK店","editable":true,"source":"system_default"},
    {"field":"reporter","label":"报修人员","value":"白云翔","editable":true,"source":"system_default"},
    {"field":"date","label":"报修日期","value":"2026-11-04","editable":true,"source":"system_default"}]},
  {"group_name":"报修内容（AI 采集整理）","items":[
    {"field":"category","label":"报修类别","value":"工程类 - 制冷设备/冷柜","editable":true,"source":"ai_filled"},

    {"field":"photos","label":"现场照片","value":"2 张","editable":true,"source":"user_edited"},
```

`POST /api/sessions/rp_9f3k2m/submit`（无请求参数，服务端以会话快照为准，order_key=会话 ID）：

## 场景 3 · 断点恢复（杀 App 后重进 / 主动退出 keep 后重进）

统一入口 `POST /api/sessions`（不带本地 session_id，恢复不依赖前端缓存）：

```json
{
  "session_id": "rp_9f3k2m",
  "is_resumed": true,
  "context": { "store": "11522 安徽商之都OK店", "reporter": "白云翔", "date": "2026-11-04", "phone_masked": "138****1234" },
  "messages": [
    { "seq": 12, "type": "confirm_card", "data": { "...": "会话内已产生的消息按 seq 重放" } },
    { "seq": 13, "type": "text", "data": { "content": "检测到未完成的报修（工程类 - 制冷设备/冷柜），继续上次填写？" } }
  ]
}
```

前端弹「继续上次报修」卡片；用户确认后按快照渲染界面。

会话内刷新 / SSE 断线重连：`GET /api/sessions/rp_9f3k2m`——结构同上，另含 `state`（当前状态机状态）与 `collected`（已采集槽位含 source），404（code 40401）时前端静默开新会话：

```json
{ "state": "PHOTO", "collected": { "category": "工程类 - 制冷设备/冷柜", "photos": ["m_001"] } }
```

## 场景 4 · 随时可改（任意状态打字，状态不变）

在 EXPECT 态打字改电话：

```json
{ "type": "text", "content": "电话换成店长的 13900005678" }
```

```
event: typing
data: {}

event: message
data: {"seq":13,"type":"text","data":{"content":"已把联系电话更新为「139****5678」，继续当前的步骤就行。"}}

event: done
data: {"state":"EXPECT"}
```

> `done.state` 与改前相同——改普通字段原地覆盖槽位、**不回退流程**；快照已更新（先存再推）。

CONFIRM 态重选类别（例外，回跳）：发 `{"type":"enum_pick","value":"工程类 - 照明/招牌"}` → 状态机按 recat 处理 → `done` 返回 `{"state":"PHOTO"}`（照片要求可能变化，联动重校验）。

## 场景 5 · 异常与降级

**提交缺字段（422）**——`POST /submit` 时照片缺失：

```json
HTTP/1.1 422
{ "code": 42201, "message": "还有 1 项没填：现场照片" }
```

前端留在 CONFIRM 态高亮缺失项（或按接口文档错误码表收 confirm_card.missing）。

**会话 LLM 次数超限（429 → 降级卡片向导）**——打字消息仍返回 SSE，但不再调 LLM：

```
event: message
data: {"seq":14,"type":"system_tip","data":{"content":"AI 手速有点慢，先用卡片点选填，一样能交单","level":"warn"}}

event: message
data: {"seq":15,"type":"enum_card","data":{"mode":"full","options":["（全量类别列表，来自字典）"],"preselect":-1}}

event: done
data: {"state":"FALLBACK"}
```

**LLM 服务不可用（503）**：

```json
HTTP/1.1 503
{ "code": 50301, "message": "AI 暂时不可用，已切换为卡片填报" }
```

**明道云提交失败（待发表机制，建议新增错误码 50302）**：

```json
HTTP/1.1 503
{ "code": 50302, "message": "提交暂时失败，已记录自动重试；紧急请联系客服 400-xxx-xxxx" }
```

> 对应 cl.md §8.4：会话保持 CONFIRM、写 pending_submit、定时重试 3 次、耗尽转人工；order_key 全程复用防重复入库。50302 需在接口文档 §3 错误码表补行。

## 场景 6 · 主动退出

**keep（保存草稿）**：

```json
POST /api/sessions/rp_9f3k2m/exit
{ "mode": "keep" }
→ 200 { "result": "ok", "draft_expired_at": "2026-11-11T09:41:00+08:00" }
```

**abandon（放弃）**：

```json
{ "mode": "abandon" }
→ 200 { "result": "ok" }
```

abandon 后再 `GET /api/sessions/rp_9f3k2m` → 404 `{"code":40401,"message":"会话不存在或已废弃"}`，前端静默开新会话。

## 附 · 报文自查清单（前端联调前过一遍）

| 检查项 | 口径 |
|---|---|
| seq 连续性 | 每条 message.seq 严格递增；重连后从快照重放不重不漏 |
| SSE 事件 | 只有 typing / message / done 三种 event；`: ping` 心跳按注释行忽略 |
| 状态一致性 | 每条 done.state 与前端当前步骤对应；改字段消息的 done.state 不变 |
| 手机号 | 任何出参不出现完整手机号（掩码 138\*\*\*\*1234）；入参 phone 走 11 位正则 |
| 枚举值 | enum_card.options / seg_pick.value 全部来自服务端字典，前端不自持枚举 |
| 幂等 | submit 重复点击只产生一个 order_key；重试返回同一单号 |
