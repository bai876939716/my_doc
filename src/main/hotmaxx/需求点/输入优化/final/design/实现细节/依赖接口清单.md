# 依赖接口清单
---

## 一、需要提供的接口

### 1. 员工手机号查询

| 项 | 内容 |
|---|---|
| 用途 | 报修单"联系电话"默认取登录人手机号（店员可改） |
| 请求 | uid → 返回手机号（最好同时带姓名，用于"报修人"默认值） |
| 频率 | 每次建会话 1 次 |

### 2. 报修单查询（列表 + 详情）

| 项 | 内容                                    |
|---|---------------------------------------|
| 用途 | AI 填报提交后，店员在「报修记录」查看历史单据与处理进度         |
| 请求 | 按**用户**过滤的列表（单号、类别、状态、提交时间）；内容和新版保修一致 |

### 3. 明道云建单（开放接口 + 权限）

| 项 | 内容 |
|---|---|
| 用途 | 服务端单账号代理提交报修单（业务身份写在字段里，不占门店账号） |
| 需要 | 门店报修工作表的写入 API 与授权； |

### 4. 类别字典导出

| 项 | 内容 |
|---|---|
| 用途 | 报修类别枚举（含细分）与各类别拍摄要求清单 |

## 二、需要开通的权限与环境

| # | 项 | 说明 | 提供方 |
|---|---|---|---|
| 1 | OSS 上传凭证 | 照片/视频存 OSS（单文件 ≤10MB） | 基础设施 |
| 3 | 网关路由 | `/agent/**` 指向 Agent 服务；**response-timeout 须大于 SSE 会话时长**（≥120s） | 平台组 |
