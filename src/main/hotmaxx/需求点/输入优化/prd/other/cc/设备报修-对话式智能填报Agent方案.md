# 设备报修 · 对话式智能填报 Agent 方案

> 在现有 App / 网页新增聊天入口，AI 引导完成报修填报，不替换老表单。
> 核心结论：**13 个字段中，系统带出 10 个、枚举点选 1 个，用户实际只需回答 2 个问题 + 确认 1 次摘要。**
> 版本 v2 · 2026-10-31

---

## 1. 入口与共存

- App 首页 / 工作台新增「智能报修」卡片；网页端在报修页顶部加「AI 帮我填」入口
- 老表单原样保留；聊天窗右上角常驻「转老表单」按钮，一键互切
- 两边草稿独立保存、互不覆盖；切换时已填内容自动映射到目标端，不重填

## 2. 设计原则（六条）

| # | 原则 | 落地方式 |
|---|------|----------|
| 1 | 新增入口不替换 | 聊天与老表单并存，一键互切，草稿隔离 |
| 2 | AI 预填、人确认 | 可查字段自动带出，摘要页集中确认、可改 |
| 3 | 能查不问、只问该问 | 账号/门店主数据可查的不问，仅问照片与详情 |
| 4 | 一次一问、枚举只选不编 | 枚举字段全部出卡片，无自由输入框，防幻觉 |
| 5 | 高频先行 | 进入即出高频报修类别卡片，点选直达、少轮次 |
| 6 | 全程可改、随时可退 | 任意字段点 ✏️ 可改；任意时刻可转老表单带走已填内容 |

## 3. 字段填报策略（13 字段三分类）

### A. 系统带出，不问用户（10 个）

| 字段 | 来源 | 说明 |
|---|---|---|
| 联系人 | 登录账号 | 默认本人；摘要页可改（代报场景写店长等） |
| 手机号码 | 登录账号 | 默认 +86；可改，提交前校验格式 |
| 门店编号 | 账号绑定门店 | 未绑定时：搜编号/店名 → 从门店主数据选中，不可手输 |
| 门店名 | 随门店编号带出 | — |
| 大区 | 随门店带出 | 兜底：查不到时出枚举卡片（选项固定） |
| 门店属性 | 门店主数据 | 兜底：枚举卡片 |
| 门店地址 | 随门店带出 | 可改 |
| 营业时间 | 门店主数据 | 选填，带出即不问 |
| 报修单编号 | 提交时系统自动生成 | — |
| 报修单状态 | 系统字段 | 提交后置「后台流转」，不问 |

> 门店联动：门店编号一旦确定（绑定或搜索选中），大区 / 门店名 / 属性 / 地址 / 营业时间 5 个字段自动带出。

### B. 枚举卡片选择，禁止手输（1 个，必问）

| 字段 | 交互 |
|---|---|
| 报修类别 | 高频卡片 +「更多类别」二级卡片，只点选。**选错会被后台驳回重提**，摘要页重点提示可改 |

（类别选项以系统实际枚举配置为准，下文卡片仅为示意。）

### C. 必须问用户（2 个）

| 字段 | 交互 |
|---|---|
| 问题照片或视频 | 拍照 / 上传；按类别下发拍摄要点，AI 校验是否拍齐，缺项提示补拍 |
| 报修详情 | 用户口语描述 → AI 整理成结构化草稿（现象 / 时间 / 影响）→ 用户「直接用 / 我来改」 |

## 4. 产品流程

```
进入聊天 → 身份预填 → 高频卡片 → 类别点选 → 照片上传 → 口述详情
→ AI 整理草稿 → 摘要确认 → 提交 → 单号反馈
```

1. **进入**：读登录态，带出 10 个系统字段，以「已为你带出」信息卡展示，不出题
2. **高频卡片**：出高频报修类别（示意：制冷设备 / 收银打印 / 取袋机 / 照明电路 / 卷帘门 / 更多）；点卡片即跳过类别追问
3. **类别点选**：未命中高频 → 二级卡片逐级选，全程无输入框
4. **照片上传**：按类别给拍摄要点；**购物袋（取袋机）类别按配置清单逐项校验——须拍到袋底供应商标识 + 问题部位，缺项必须补拍再继续**
5. **口述详情**：一次一问，用户想到什么说什么；AI 整理草稿请确认
6. **摘要确认**：全部字段卡片式列出，系统带出的灰显、问来的高亮，均可 ✏️；类别字段标注「选错将被驳回」
7. **提交**：生成报修单编号，状态置「后台流转」，进度走 App 推送
8. **兜底**：「转老表单」随时可用，已填内容自动映射到对应字段

## 5. 模拟对话剧本（冷柜不制冷）

> 场景：门店店员小李，账号已绑定门店 S1052。UI 元素用【】标注。

**Agent**：你好，我是智能报修助手。已带出你的门店信息：
【信息卡 · 系统带出】大区：华南 ｜ 门店：S1052 · 好特卖 XX 路店 ｜ 联系人：李某某 138\*\*\*\*5678
这次要报修什么？
【高频卡片】❄️ 制冷设备 ｜ 🖨️ 收银打印 ｜ 🛍️ 取袋机 ｜ 💡 照明电路 ｜ 🚪 卷帘门 ｜ 📋 更多类别

**小李**：（点）制冷设备

**Agent**：具体哪类制冷问题？
【选项】不制冷/制冷差 ｜ 柜体破损 ｜ 异响/漏水 ｜ 门封/玻璃 ｜ 其他

**小李**：（点）不制冷

**Agent**：好的，报修类别：制冷设备 - 不制冷/制冷差。
请拍照或录视频让我了解情况：
📸 建议拍到：① 整柜外观 ② 温度显示 ③ 故障部位
【拍照 / 上传】

**小李**：（上传 2 张照片）

**Agent**：照片收到 ✅（识别到：冷藏柜，柜温显示 12℃）
简单说说情况？什么时候发现的、有什么影响，想到什么说什么。

**小李**：昨天下午就发现酸奶那排有点温，今早整柜都不凉了，温度显示12度，冷藏的酸奶乳制品都下架了不敢卖

**Agent**：帮你整理好了报修详情，请确认：
> 昨日（10-30）下午发现冷藏柜制冷异常，今早加剧、整柜不制冷，柜温显示 12℃；已下架柜内酸奶、乳制品等冷藏商品，影响正常销售，请尽快上门维修。
【直接用】｜【我来改】

**小李**：（点）直接用

**Agent**：信息齐了，请最后确认：
【摘要卡】
- 报修类别：制冷设备 - 不制冷/制冷差 ⚠️ 选错将被驳回 ✏️
- 门店：S1052 好特卖 XX 路店（华南 · XX 市 XX 路 8 号）✏️
- 联系人：李某某 138\*\*\*\*5678 ✏️
- 照片/视频：2 张 ✏️
- 报修详情：见上文草稿 ✏️
- 报修单编号：提交后自动生成
【提交】｜【转老表单核对】

**小李**：（点联系人 ✏️，改为：王店长 139\*\*\*\*0000）

**Agent**：已更新联系人：王店长 139\*\*\*\*0000。可以提交了吗？
【提交】

**小李**：（点）提交

**Agent**：提交成功 🎉
报修单号：**BX-20261031-0847**，状态：后台流转。维修进度会推送通知你。
还需要报修其他设备吗？【继续报修】｜【完成】

### 购物袋（取袋机）分支差异

类别点「取袋机（购物袋）」后，照片环节改为强制清单校验：
📸 须拍到 **① 袋底供应商标识 ② 问题部位**（以系统配置为准），AI 逐项核对，缺项提示「还差一张：袋底供应商标识」，补齐才放行——避免后台因照片不达标驳回返工。

### 剧本设计点（对照原则）

开场信息卡=能查不问（10 字段零提问）· 类别两次点选=一次一问+枚举只选不编 · 拍摄要点下发=条件化引导降驳回 · AI 整理草稿=预填人确认 · 摘要页改联系人=全程可改 · 「转老表单核对」常驻=不替换可回退

## 6. 边界与兜底

- 账号未绑定门店 / 督导跨店报修：搜索选门店，关联 5 字段重新联动带出
- 类别想改：摘要页点类别卡片重选即可，不必重走全程
- 老表单用户切进聊天：老表单已填内容同样映射进来，不重填
- 所有枚举选项读后台配置，不由模型生成，杜绝编造选项
