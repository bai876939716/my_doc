# 01 · 页面嵌入指南

正式版 HTML 是一个自包含的单文件页面（无构建、无外部依赖、无网络字体），放进 WebView 就能跑。本文说清楚怎么配置、要接哪三个钩子。

## 一、最小可用接入

1. 把 `门店报修-AI填报-正式版.html` 作为 App 内置资源（或下发地址）加载进 WebView；
2. 页面加载**之前**注入配置（Android 用 evaluateJavascript 前先 addJavascriptInterface 或直接在 HTML 前插 script；iOS 用 WKUserScript）：

```js
window.__REPAIR_CONFIG__ = {
  apiBase: 'https://gateway-dev.hotmaxx.cn/agent/repair/v1',  // TODO(上线): 换生产网关地址
  storeNo: '11522',      // 必填。门店编号，从入口带入（用户在哪个店点报修就传哪个店）
  storeName: '安徽商之都OK店',  // 选填。仅用于连接前的占位展示，真值以服务端 status_bar 下发为准
  // uid: 不要传——见下节身份说明
};
```

3. 接好下节三个钩子，完成。

漏了 `storeNo` 页面会停在「未获取到门店信息」的提示页（这是有意行为，不给后端一个空门店）。

## 二、三个必接钩子

页面把「调相机、跳页面、关 WebView」三件事留给宿主 App，全部通过 `window.__REPAIR_CONFIG__` 上的函数注入：

### 1. `uploadPhotos(needCount) => Promise<[{name, url}]>`

拍照引导卡上点「＋ 拍照 / 上传」时被调用。宿主要做：调起相机/相册 → 走**现有明道云上传接口**直传 → 返回附件清单。

```js
window.__REPAIR_CONFIG__.uploadPhotos = async function (needCount) {
  // 1. 调起相机或相册，拿到本地文件
  const files = await nativePickPhoto(needCount);
  // 2. 逐个走现有明道云上传接口，拿到 serverName 和 key
  const list = [];
  for (const f of files) {
    const r = await uploadToMingdao(f);
    // 3. 拼完整 URL：serverName 去掉尾部斜杠 + '/' + key
    const url = r.serverName.replace(/\/$/, '') + '/' + r.key;
    list.push({ name: decodeURIComponent(f.name), url });
  }
  return list;   // [{name, url}]，url 必须是完整 http(s) 地址
};
```

注意：`name` 要解码并保留扩展名；`url` 不要重复拼 bucket/filePath。Agent 侧不再有上传接口，传 `m_001`、`blob:` 之类假引用会被当普通字符串处理，图片显示不出来。

### 2. `onViewRecords(orderNo) => void`

结果卡上点「📋 查看报修记录」时被调用。宿主跳到 App 已有的报修记录页（可带单号）。

### 3. `onLeave() => void`

用户选择离开（存草稿/放弃/已提交后返回）时被调用，此时 exit 接口页面已经调完。宿主关 WebView 或返回表单页。不接的话页面停在「已退出」态，仍可点按钮重进（浏览器预览时就是这样）。

## 三、身份链路（重要，别踩坑）

- **经网关（App 正式链路）**：App 只带 HotShop 登录 token + `X-PlatformId`，网关验 token 后写入用户头，Java 转发层转成 `X-Uid` 传给 Agent。**前端代码里不要出现 X-Uid，也不要给页面配 uid**。
- **WebView 直连后端（仅联调）**：没有网关帮忙，必须配 `uid`（员工 ID），否则五个业务接口一律 `401 / 40101`。页面会自动把它放进 `X-Uid` 请求头。
- 经网关联调收到 401 → 是登录态或网关/Java 转发配置问题，找后端查链路，不是页面的问题。

## 四、URL 参数临时覆盖（联调方便）

不注入配置也可以直接用 URL 参数试：

```
门店报修-AI填报-正式版.html?api=http://192.168.1.5:8000&uid=test001&store_no=11522&store_name=测试店
```

`api` 不带协议时默认补 `http://`。优先级：URL 参数 > `__REPAIR_CONFIG__` > 页面默认值（默认 `http://localhost:8000`）。

## 六、页面已内置、宿主不用管的行为

- 会话加速重进：页面自己把 session_id 存 localStorage，重进先查会话恢复现场，查不到（过期/被清）自动重开新会话；
- 40401（会话没了）静默重建；网络失败自动全量对齐（调会话查询接口拉全部消息补渲染）；
- 手机号出参一律掩码（`138****1234`），页面不会显示完整号码；
- 文本超 500 字、手机号格式、单会话最多 5 张照片，页面本地都拦了；
- 用户点返回时的三选一弹窗（继续填写 / 存草稿离开 / 放弃本次）已内置，选完自动调 exit 接口再回调 `onLeave`。
