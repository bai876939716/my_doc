## 前端要做的三件事

1. **嵌页面**：把正式版 HTML 放进 WebView，注入 `window.__REPAIR_CONFIG__`（apiBase、storeNo 等，见 01）；
2. **接钩子**：实现 `uploadPhotos` / `onViewRecords` / `onLeave` 三个 JS 钩子（见 01，各约 10 行代码）；
3. **加入口**：在现有报修表单页顶部加一张「AI 智能填报」入口卡片（片段在 01，拷走即用），点击带 `store_no` 进入页面。

## 三条必须先知道的口径

1. **没有 SSE/WebSocket**——每轮对话 = 一次普通 `POST` + 一个 JSON 响应（`state / focus / messages` 三个字段），fetch 常规写法；
2. **页面不持有业务状态**——"现在该干什么"永远以服务端响应为准（state + focus 驱动渲染），本地只存 session_id 作加速；
3. **枚举值全部来自服务端**——卡片里的选项、确认单的内容都是响应里带好的，前端不自造字典。
