# 核心数据模型说明

## xinyu-agents — Pydantic 数据模型

### Stranger Feed 模型链

```python
# 入参
class StrangerFeedInput(BaseModel):
    source_locale: str                     # "zh-CN" | "zh-TW" | "en-US"
    character_id: str
    character_name: str
    quantity: int = 8                      # 1-32
    character_persona: str                 # 长文本，角色人设
    character_home_location: str
    world_lore_locations: dict             # 星球/区域/地点树
    bonded_characters_list: list[BondedCharacter]
    existing_library_posts: str = ""       # 已有库存摘要（避免重复）

# LLM 生成的中间状态（单语）
class FeedPostSourceItem(BaseModel):
    suggested_time: Literal["morning", "afternoon", "evening", "night"]
    content: str                           # 正文
    image_description: str
    comments: list[CommentItem]

# 最终落库结构（多语言合并）
class FeedPostItem(BaseModel):
    suggested_time: str
    locales: dict[str, PostLocaleBody]     # { "zh-CN": {...}, "zh-TW": {...}, "en-US": {...} }

class PostLocaleBody(BaseModel):
    content: str
    image_description: str
    comments: list[CommentItem]

class CommentItem(BaseModel):
    commenter_character_id: int
    comment_content: str
```

### Acquaintance Feed 模型链

```python
# 入参（含时区）
class AcquaintanceFeedInput(BaseModel):

    user_nickname: str | None
    bonded_characters_list: list[BondedCharacter]
    # ... 更多字段

# LLM 生成（单个对象，非数组）
class AcquaintancePostSourceItem(BaseModel):
    dynamic_time: str                     # 用户本地时间 ISO 8601
    content: str
    image_description: str
    comments: list[CommentItem]

# 出参
class AcquaintanceFeedWorkflowResponse(BaseModel):
    success: bool
    posts: list[AcquaintanceFeedPostItem] # 恒长度 1
    time_validations: list[TimeValidationReport]  # 非阻断校验
```

## xinyu-world-simulator-core — 数据库表结构

### 星梦系统核心表

#### tb_soul_haven_star_dream（星梦任务主表）

```sql
CREATE TABLE tb_soul_haven_star_dream (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    save_id             VARCHAR(64),
    character_ids       BIGINT[] NOT NULL,        -- 参与角色（含主角+配角）
    status              VARCHAR(32) NOT NULL,      -- PENDING/ACTIVE/ENDED/EXPIRED
    hermes_session_id   VARCHAR(128),             -- Hermes 长连接会话
    chat_session_id     VARCHAR(128),             -- 聊天会话 ID
    open_ing_text       TEXT,                     -- 开场白文本
    scene_overview      TEXT,                     -- 场景概述
    star_dream_event_id BIGINT,                   -- 关联星梦事件
    invite_id           BIGINT,                   -- 关联邀请记录
    created_at          TIMESTAMPTZ(6),
    updated_at          TIMESTAMPTZ(6),
    ended_at            TIMESTAMPTZ(6)
);
-- 索引: (user_id, save_id), (status, created_at)
```

#### tb_soul_haven_generation_dream_inventory（星梦库存表）

```sql
CREATE TABLE tb_soul_haven_generation_dream_inventory (
    id              BIGSERIAL PRIMARY KEY,
    dream_id        VARCHAR(128) UNIQUE NOT NULL,
    user_id         BIGINT NOT NULL,
    save_id         VARCHAR(64),
    character_id    BIGINT NOT NULL,
    opening_line    TEXT,                        -- 开场白
    scene_overview  TEXT,
    dream_type      VARCHAR(8),                  -- "1"单人 | "2"多人
    source          VARCHAR(32),                 -- 预制/改写/新生产
    relationship_level INT,                      -- 生产时的 Lv
    status          VARCHAR(32),                 -- AVAILABLE/CONSUMED/EXPIRED
    is_first_encounter BOOLEAN DEFAULT FALSE,
    created_at      TIMESTAMPTZ(6),
    consumed_at     TIMESTAMPTZ(6)
);
```

#### tb_soul_haven_generation_daily_plan（用户日内容计划）

```sql
CREATE TABLE tb_soul_haven_generation_daily_plan (
    id          BIGSERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL,
    save_id     VARCHAR(64),
    plan_date   DATE NOT NULL,                   -- 计划日期
    time_slot   VARCHAR(8),                      -- "W01" - "W12"
    dream_id    VARCHAR(128),                    -- 关联星梦库存
    status      VARCHAR(32),                     -- SCHEDULED/DELIVERED/SOFT_DELETED
    created_at  TIMESTAMPTZ(6)
);
-- 索引: (user_id, save_id, plan_date)
```

#### tb_soul_haven_generation_star_event（星事表）

```sql
CREATE TABLE tb_soul_haven_generation_star_event (
    id              BIGSERIAL PRIMARY KEY,

    publisher_id    BIGINT,                      -- 发布角色 ID

    content         TEXT,                        -- 星事内容
    publish_status  VARCHAR(32),                 -- PENDING/PUBLISHED
    publish_time    TIMESTAMPTZ(6),
    trigger_type    VARCHAR(32),                 -- 星梦结束/定时/手动
    created_at      TIMESTAMPTZ(6)
);
```

#### tb_soul_haven_star_dream_invite（邀请记录表）

## API 接口契约（Protobuf）

### 星梦 RPC 接口（核心方法）

```protobuf
service StarDreamRpcService {
  // 查询当前进行中星梦
  rpc QueryCurrentStarDreamByCharacter(QueryCurrentRequest) returns (StarDreamResponse);
  
  // 批量查询多角色当前星梦
  rpc QueryCurrentStarDreamByCharacters(QueryMultiCurrentRequest) returns (MultiStarDreamResponse);
  
  // 创建邀请卡（短对话意图识别触发）
  rpc CreateStarDreamInviteCard(CreateInviteCardRequest) returns (InviteCardResponse);
  
  // 查询星梦事件列表（地图/星球入口）
  rpc QueryStarDreamEventsByCharacters(QueryEventsRequest) returns (EventsResponse);
  
  // 查询历史回忆列表
  rpc QueryStarDreamRecallsByCharacter(QueryRecallsRequest) returns (RecallsResponse);
  
  // 查询会话详情（消息列表）
  rpc QueryStarDreamSessionDetailBySessionId(SessionDetailRequest) returns (SessionDetailResponse);
}
```

### 星梦 HTTP BFF 接口（App 调用）

```
GET  /stardream/current                     # 获取进行中星梦
```

## 错误码体系

### xinyu-agents 错误码

| 错误码 | 含义 | 是否阻断 | 所在 Agent |
|--------|------|----------|-----------|
| `PARAM_INVALID` | 入参校验失败 | 是 | 全部 |
| `LLM_FAILED` | 模型调用异常 | 是 | 全部 |
| `PARSE_FAILED` | JSON 解析失败 | 是 | 全部 |
| `SCHEMA_FAILED` | Pydantic 校验失败 | 是 | 全部 |
| `RULE_FAILED` | 输出规则不通过 | 是 | Stranger Feed |
| `TRANSLATION_FAILED` | 翻译步骤失败 | 是 | Stranger Feed |
| `MCP_NOT_CONFIGURED` | MCP 未配置 | 是 | Stranger Feed |
| `MCP_FAILED` | MCP 工具调用失败 | 是 | Stranger Feed, Xingmeng |
| `ASSEMBLE_POST_FAILED` | 组装动态失败 | 是 | Acquaintance Feed |

### xinyu-world-simulator-core 业务错误码（部分）

| 错误码 | 含义 |
|--------|------|
| `STAR_DREAM_CONFLICT` | 已有进行中星梦，冲突 |
| `STAR_DREAM_INVITE_RATE_LIMIT` | 邀请频率超限（10分钟冷却） |
| `STAR_DREAM_INVITE_DAILY_LIMIT` | 今日邀请次数超限（8次） |
| `STAR_DREAM_REJECT_COOLDOWN` | 拒绝冷却中（5分钟） |
| `STAR_DREAM_ACCEPT_LOCK` | 接受锁定中（防并发） |
| `SHELL_INSUFFICIENT` | 贝壳余额不足 |
| `AGENT_OUTPUT_RULE_FAILED` | Agent 输出规则不通过（Java 落库前阻断） |
