实时对话 Agent（qwen3-max · 主动配额控制 8,192 tokens）

聊天 Agent 使用 qwen3-max（实际 context window = 262,144 tokens），但系统主动限制每次调用的 Prompt 预算为 8,192 tokens（可用预算 ≈ 85% = 6,963 tokens），原因是：

  • 降低每次调用成本（按 token 计费）
  • 控制首 token 延迟（P99 < 2s 要求）
  • 对话场景无需超长上下文，40 轮短期 + 5 条长期记忆已覆盖需求

⚠ 8,192 是配置的预算上限，不是模型的实际 context window。模型实际支持 262,144 tokens，预算上限通过 Nacos 热配置随时可调。
