## 一、基础概念区分
| 站点地址 | 产品属性 | 能否生成API Key |
| ---- | ---- | ---- |
| `claude.ai` | 网页端对话产品（Pro/Max订阅） | ❌ 无法直接生成原生API Key，仅附赠月度API额度 |
| `console.anthropic.com` | 官方开发者后台 | ✅ 唯一原生`sk-ant-`格式密钥签发入口 |

> 密钥格式说明：
> - 官方原生密钥：`sk-ant-xxxx`
> - 中转平台密钥：平台自定义前缀，调用需替换BaseURL

## 二、渠道1：Anthropic官方开发者控制台（原生Key）
### 1. 申请步骤
1. 网络：境外合规网络环境访问`console.anthropic.com`
2. 注册：Gmail/Outlook国际邮箱注册，完成邮箱+境外手机号（美/加/欧盟号码）双重验证
3. 账单：绑定境外Visa/Mastercard外币信用卡，账户最低预存5USD起充
4. 生成密钥：侧边栏`Settings > API Keys > Create new key`，命名后即时复制保存（页面关闭不可二次查看）

### 2. 计费（官方原价，按百万Tokens计价）
| 模型 | 输入($/1M tokens) | 输出($/1M tokens) | 上下文上限 |
| ---- | ---- | ---- | ---- |
| Claude Haiku | 0.25 | 1.25 | 200K |
| Claude Sonnet3.5 | 3.00 | 15.00 | 1M |
| Claude Opus | 5.00 | 25.00 | 1M |

### 3. 优缺点
- 优点：原生直连、新模型优先上线、全量官方接口、无中间篡改
- 缺点：需境外手机号+外币信用卡，IP环境波动易触发账号风控封禁，国内调用必须境外网络

### 4. 适用场景
海外常驻开发者、跨境商用项目

## 三、渠道2：海外云厂商授权通道（AWS Bedrock / Azure AI Foundry / GCP Vertex）
> Anthropic官方授权全球云厂商上架Claude全系模型，在云厂商控制台独立生成密钥，不经过Anthropic官网
### 1. AWS Bedrock
1. 开通AWS账号，进入Bedrock服务，在模型权限页申请Claude系列模型白名单
2. 开通后在IAM/API密钥管理生成专属调用凭证
3. 调用格式使用Bedrock专属modelId，不兼容原生Anthropic SDK默认参数

### 2. Azure AI Foundry
1. 注册微软Azure账号，创建AI资源实例
2. 资源市场订阅Claude模型，在密钥面板生成Endpoint+API Key

### 3. GCP Vertex AI
1. 开通GCP项目，开启Vertex API权限
2. 申请Claude模型接入权限，生成项目调用密钥

### 优缺点
- 优点：企业合规结算、支持国内银行卡/对公充值、全球多节点，部分国内云区直连无需境外网络、配套云原生权限管控
- 缺点：开通流程繁琐，个人小额使用成本偏高，接口格式和原生API存在差异需要适配

### 适用场景
企业项目落地、生产环境部署、合规商用开发

## 四、渠道3：Claude Pro/Max订阅会员附赠API额度
### 1. 获取规则
- Claude Pro：20USD/月，每月赠送固定额度API调用余额，额度仅限当月，月末清零不结转
- Claude Max：分级套餐（100USD+/月），附赠更高额度API资源，优先队列调用

### 2. 领取方式
1. `claude.ai`官网使用境外信用卡/美区Apple ID开通月度订阅
2. 在会员权益页面领取月度API Credit，绑定至开发者控制台账户后生成可用API Key

### 优缺点
- 优点：网页对话+API调用共用一个账号，轻度测试无需额外充值API余额
- 缺点：固定月订阅成本，超额调用需额外在控制台充值，国内调用API仍需要境外网络

### 适用场景
个人日常调试、小体量临时开发

## 五、渠道4：官方学生专项免费API计划
### 1. 申请门槛
1. 持有海外院校`.edu`后缀教育邮箱、有效在校学籍证明
2. 已注册`console.anthropic.com`并完成手机号验证（新用户默认5USD新人免费额度）
3. 项目仅限学业/个人非商用开源项目，企业实习、商用项目无法通过审核

### 2. 福利内容
审核通过一次性赠送50USD免费API额度，有效期90天，额度内免费调用全系Claude模型。

### 优缺点
- 优点：零成本原生官方密钥
- 缺点：仅限海外在校学生，国内高校edu邮箱无法参与活动，调用仍需境外网络

## 六、渠道5：第三方API中转聚合平台
### 1. 原理说明
平台批量采购官方Claude API额度，搭建中转网关，封装统一调用接口，用户在平台注册生成专属密钥，调用时替换官方BaseURL即可兼容原生SDK。

### 2. 开通流程
1. 平台官网手机号/邮箱注册
2. 微信/支付宝人民币充值（多数平台1元起充，新用户赠送小额免费体验额度）
3. 个人控制台→密钥管理→创建API Key，同时获取平台专属请求地址(BaseURL)

### 优缺点
- 优点：无需境外手机号、外币卡，国内网络直连无需代理，人民币结算，入门门槛最低
- 缺点：相比官方定价存在10%~20%溢价，需甄别平台稳定性，劣质平台存在替换廉价开源模型风险

### 适用场景
绝大多数国内个人开发者、本地调试、小型项目开发

## 七、渠道6：高危不合规渠道（避坑清单）
| 售卖形式 | 风险说明 |
| ---- | ---- |
| 电商平台零散售卖单条Key、共享账号密钥 | 账号多人共用极易被官方批量风控封禁，密钥随时失效，用户上传数据存在泄露被盗风险 |
| 低价无限调用Claude API | 绝大多数替换为国产开源大模型(DeepSeek、GLM等)，非原生Claude，返回逻辑失真 |
| 个人私售爬虫逆向接口 | 依托网页爬虫反向封装接口，官方版本更新即失效，隐性预设系统提示词篡改输出 |

> 备注：任何“永久无限官方原生Key”均为骗局。

## 九、API密钥通用安全规范
1. 密钥仅生成时完整可见，务必即时备份，平台关闭页面无法找回；
2. 禁止将密钥明文写入代码、提交至代码仓库；
3. 不同项目单独创建独立API Key，单密钥泄露不影响其他业务；
4. 长期闲置不用的密钥在对应后台删除，降低泄露风险。
