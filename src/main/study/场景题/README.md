## 使用建议

- 每篇文档开头都有"一句话答案"，先背这个，展开细节按面试官追问程度自由发挥
- 涉及"xinyu 项目现状"的部分，都标注了对应的原始文档出处（`02-系统架构介绍.md`、`06-记忆系统设计.md` 等），可以回头核对
- 涉及"业内通用做法"和"Harness 层面"的部分是通用工程知识，可以放心讲，不依赖具体项目实现
- 凡是标注"文档没有明确依据，属于推导"的地方，面试时如果被追问具体实现细节，诚实说"这部分我们没有做/没细看"，比编造具体机制更安全
