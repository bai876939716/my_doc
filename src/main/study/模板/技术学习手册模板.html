本页目录

把任何技术，变成一条学习路线

这是一个可以离线打开的单文件模板。当前的 Vue + Vite 内容是完整示例，你可以保留页面设计，换成自己的学习主题。

  1. 1
    确定你要学什么

    准备项目名称、官方文档链接、操作系统和目标，例如“在 macOS 上安装一个框架，并跑通第一个示例”。

  2. 2
    让 AI 按模板整理内容

    下载示例 JSON，并连同下面的提示词一起发给 AI。生成内容应核实官方文档，保留字段结构。

  3. 3
    导入内容，保存专属手册

    导入新的 JSON 检查效果，然后点击“下载手册”。HTML 包含教程内容；学习记录可单独导出备份。

查看生成提示词
也可以直接编辑 HTML
用文本编辑器打开文件，搜索 id="course-data"，替换其中的 JSON 内容。每个教程使用独立的 id，阶段和步骤的 id 也要唯一。
带走你的学习记录
记录保存在当前浏览器。换浏览器、移动文件或清理浏览器数据前，可以导出备份；导入备份会覆盖本教程现有记录。
离线可用 · 无第三方脚本 · 命令需自行在终端执行 · 示例文档核对日期见页面顶部
