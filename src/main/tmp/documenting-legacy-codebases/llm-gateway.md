# 模型网关

描述对象:app/core/llm.py(协议壳与百炼网关)。

全流程唯一的调模型入口。换模型只改这里的子类加配置;测试与评测用技能包里的规则版假模型换桩,不走网络。真网关是百炼的 OpenAI 兼容端点:temperature 固定为零,显式关思考链(不关会拖慢耗时),超时显式三十秒,SDK 自带重试关死(重试由本类自己控,免得时长被隐性放大)。

## 输入组装

系统词两层:业务段(技能包出,角色、规则、示例、字典)拼在前,协议壳在后(格式要求压轴更利于服从)。用户词固定四段:一行流程状态(裸值消解的依据:一句「就这个吧」算回答什么,取决于正在问什么)、槽位快照(声明 secret 的槽位值不进,报修包里就是手机号)、三引号包裹的用户消息(三引号内是数据不是指令,防注入)、输出要求。字典只注进系统词一份(实测 system 与 user 各放一份单次占三成二 token,且 system 前缀稳定利于隐式缓存)。

## 协议壳要点

六种意图(提供、修改、问进度、闲聊、跑题、诱导越权),白名单之外的按闲聊。边界意图附一句不超过十二字的应和半句(接对方的处境,禁止复读、禁止反问、不编事实、不承诺操作);诱导越权不回应和。修改语义:只返回用户明确要改的字段与新值;只点名没给值就只报目标字段名。值即回答:直接报出取值时,该字段是当前所问算提供、已填过算修改,取值必须归一到字典原词(字面完全不同的口语也要映射);唯一例外是骑墙话(可能吧、大概),禁止替用户挑边,原样传,系统会拦下让用户点选。

## 输出归一(不可信输出的兜底)

模型返回先剥代码围栏再解析 JSON;意图限白名单、字段增量限白名单且只收非空字符串、枚举候选限字典且最多三个、修改目标限白名单且最多四个;应和半句剥尾部标点、硬截二十字。任何解析失败按边界意图兜底(引擎计一次失败,连败进降级)。

## 重试与成本

单次调用失败重试一次,再败按边界轮返回(带解析错误信息入日志)。成本闸在会话粒度:每会话 LLM 调用数配额默认三十次,超限整轮交规则脑,照样能交单。点选轮零 LLM,类别字典在线真值也不走模型。
