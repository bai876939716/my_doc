# 技能包契约与报修包

描述对象:app/core/skill_contract.py(契约)与 app/skills/repair/(报修包实现)。

技能包是纯声明:槽位、话术、字典、工具、卡片五件套加提示词业务段。引擎与 api 层的校验口径全部从这些声明读取,所以接新业务理论上只需新目录加一份同形状路由,core 不动(仓库有 neutrality 测试守这条线)。load() 在组装时做启动自检:槽位重名、话术缺键、字典未注册、识别器或显示形态未注册、带值手势重名、带出工具形参与入口参数不匹配,任一命中直接拒绝启动;快捷卡的点选值还会过一遍当前字典白名单,不在的剔除并记错误日志(不炸服务,白名单补录后重启恢复)。

## 槽位契约(报修包实际配置)

七个槽位,声明顺序即议程问序。带出组三个:门店名称(必填,不问)、报修人员(非必填,不问;允许 update 轮改名过长度闸;档案查无退空不伪造,空也放行)、报修日期(必填,不问,默认今天)。采集组四个:故障情况(自由文本,必填,上限一百字,卡片路径免问、由默认描述兜底,打字可截断收下)、报修类别(枚举,必填,挂 MustPick:AI 只能提名候选、用户点选才入库;原话唯一命中字典词可直填;被拦时用重选话术;改类别时清系统默认描述、只提示照片自查)、现场照片(附件,必填,至少一张,拍摄清单按类别现值挑)、联系电话(带出,必填,声明手机识别器、显示掩码、真号不进提示词;档案有可用默认号就发一键确认卡,没有就直接开口要;裸号码需过识别器加原话印证双闸)。

包级提交校验一条:照片至少一张(引导卡上的清单只是建议,不卡张数)。

## 字典

类别字典真值在线:从明道云分类分级表翻页拉全量行,组自引用树,一级类加拍平细分(后代一律拍平进二级,叶子主类自身是合法值)。缓存进程内 TTL 一小时;过期那一轮先把旧值给出去、刷新挪到后台线程(不让撞上的用户付明道云慢握手的成本);回源失败用最近一次成功值(过期也用),退避六十秒再试;从没成功过就降级静态字典并记错误日志。Mock 边界与建单开关同进退:开关关着用静态字典(快捷卡全量可用),开着用在线真值。大区字典同理:从报修表结构拉 Dropdown 内嵌选项,一小时一刷。

静态字典是兜底真值,叫法与在线分类表对齐(否则降级时快捷卡会被白名单全灭,代码注释点名了这条约束)。

## 工具(三个,签名即接口形状)

带出工具:入口参数 uid 加门店编号,产出门店名、报修人、日期、手机号、大区。门店与员工档案走 base-shop,同一地址;未配置全走 Mock 演示值;配置了但查无或异常,报修人退空、手机号退空,不拿 Mock 值冒充。字典工具:类别树加拍摄清单。建单工具:幂等键为(建单开关、明道云地址、工作表 id、会话 id)四元组;开关关着返回模拟单号;开着按字段映射声明组装写入明道云(类别按叶子选项 rowId 反查写入,大区按选项 key 反查写入,反查不到的记 skipped 点名、不硬写);建单成功立刻落进程内缓存占住幂等,单号回查失败用行 id 兜底。

## 快捷卡

六张:冷柜不制冷、收银机故障、照明灯不亮、空调不制冷、门头招牌灯不亮、断电着火漏水(紧急维修)。点卡零 LLM 直填类别值并切到卡片路径(描述槽免问)。

## 话术与提示词

全部中文文案集中两处:技能包话术表(开场、提问、变体)与流程话术映射(引擎通用键到报修中文,缺键启动即炸)。提示词分两层:框架层只有业务无关的协议壳(纪律、意图集、输出骨架),业务段由技能包注入并拼在协议壳前面(角色开头、格式要求压轴)。
