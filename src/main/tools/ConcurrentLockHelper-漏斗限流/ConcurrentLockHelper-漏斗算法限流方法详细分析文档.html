1. 方法概述

isAllowed 是 ConcurrentLockHelper 类中的一个核心限流方法， 基于 漏斗算法（Funnel Algorithm） 实现请求频率限制。

该方法用于判断是否允许当前请求通过，通过维护一个漏斗状态来控制请求的速率和容量。 漏斗算法可以平滑地限制请求速率，避免突发流量对系统造成冲击。

💡 核心特性：
  • 基于漏斗算法的限流实现
  • 支持容量和漏出速率两个维度的控制
  • 使用 Redis 存储漏斗状态，支持分布式场景
  • 客户端计算令牌补充，减少 Redis 访问
  • 容忍少量超限，提高系统可用性

2. 方法签名

public boolean isAllowed(String key, int capacity, int leakRatePerSecond, int expireSeconds)

参数说明

参数名 类型 说明
key String Redis 中存储漏斗状态的键。用于标识不同的限流维度（如用户ID、接口路径等）
capacity int 漏斗容量，即最大令牌数。表示漏斗最多能容纳多少个令牌
leakRatePerSecond int 每秒漏出速率，即每秒允许通过的请求数。表示漏斗每秒会漏出多少个令牌
expireSeconds int Redis key 的过期时间（秒）。用于自动清理不再使用的限流状态

返回值

返回值 类型 说明
isAllowed boolean true: 允许请求通过，已消耗一个令牌
false: 拒绝请求，当前无可用令牌

3. 算法原理

3.1 漏斗算法简介

漏斗算法（Funnel Algorithm）是一种经典的限流算法，类似于一个漏斗：

  • 容量（Capacity）：漏斗的最大容量，表示最多能容纳多少个令牌
  • 漏出速率（Leak Rate）：漏斗底部每秒漏出的令牌数量
  • 剩余容量（Left Capacity）：漏斗当前剩余的令牌数量
🎯 工作原理：
  1. 请求到达时，检查漏斗中是否有可用令牌
  2. 如果有令牌，消耗一个令牌并允许请求通过
  3. 如果没有令牌，拒绝请求
  4. 随着时间的推移，漏斗会按照漏出速率自动补充令牌

3.2 令牌补充机制

令牌的补充是通过时间差计算实现的：

// 计算自上次检查以来经过的时间（毫秒） long timePassedMillis = now - state.getNextLeakTime(); // 根据时间差和漏出速率计算应该补充的令牌数 int tokensToAdd = (int) ((timePassedMillis * state.getLeakRate()) / 1000L); // 更新剩余容量，但不能超过最大容量 int newLeftCapacity = Math.min(state.getCapacity(), state.getLeftCapacity() + tokensToAdd);
✅ 优势：
  • 客户端计算令牌补充，减少对 Redis 的访问频率
  • 支持突发流量的平滑处理
  • 可以容忍少量超限，提高系统可用性

4. 实现细节

4.1 完整方法代码

/** * 判断是否允许请求（容忍少量超限） * key: Redis 中存储漏斗状态的键 * capacity: 漏斗容量（最大令牌数） * leakRatePerSecond: 每秒漏出速率（每秒允许通过的请求数） * expireSeconds: Redis key 的过期时间（秒） */ public boolean isAllowed(String key, int capacity, int leakRatePerSecond, int expireSeconds) { // 获取或初始化漏斗状态 AtomicReference<FunnelState> stateRef = new AtomicReference<>(getFunnelState(key)); long now = System.currentTimeMillis(); FunnelState state = stateRef.get(); if (Objects.isNull(state)) { state = FunnelState.build(capacity, leakRatePerSecond, capacity, now); saveFunnelState(key, state, expireSeconds); return true; // 第一次肯定能通过 } // 补充容量（客户端计算） long timePassedMillis = now - state.getNextLeakTime(); if (timePassedMillis > Constant.ZERO) { int tokensToAdd = (int) ((timePassedMillis * state.getLeakRate()) / 1000L); int newLeftCapacity = Math.min(state.getCapacity(), state.getLeftCapacity() + tokensToAdd); state.setLeftCapacity(newLeftCapacity); state.setNextLeakTime(now); saveFunnelState(key, state, expireSeconds); } // 判断是否允许 if (state.getLeftCapacity() <= Constant.ZERO) { return false; } state.setLeftCapacity(state.getLeftCapacity() - Constant.ONE); saveFunnelState(key, state, expireSeconds); return true; }

4.2 执行流程

从 Redis 获取漏斗状态（getFunnelState）
获取当前时间戳（System.currentTimeMillis）
判断漏斗状态是否存在
如果不存在：初始化漏斗状态（容量=capacity，剩余容量=capacity），保存到 Redis，返回 true
如果存在：继续后续流程
计算自上次检查以来经过的时间（timePassedMillis）
如果时间差大于 0，计算并补充令牌
计算应补充的令牌数：tokensToAdd = (timePassedMillis * leakRate) / 1000
更新剩余容量：newLeftCapacity = min(capacity, leftCapacity + tokensToAdd)
更新下次漏出时间：nextLeakTime = now
保存更新后的状态到 Redis
检查剩余容量是否小于等于 0
如果 ≤ 0：返回 false（拒绝请求）
如果 > 0：消耗一个令牌（leftCapacity - 1），保存状态，返回 true（允许请求）

4.3 关键步骤详解

步骤 1：获取或初始化漏斗状态

// 从 Redis 获取漏斗状态 AtomicReference<FunnelState> stateRef = new AtomicReference<>(getFunnelState(key)); long now = System.currentTimeMillis(); FunnelState state = stateRef.get(); // 如果状态不存在，说明是第一次请求，初始化漏斗 if (Objects.isNull(state)) { // 构建初始状态：容量=capacity，漏出速率=leakRatePerSecond，剩余容量=capacity，下次漏出时间=now state = FunnelState.build(capacity, leakRatePerSecond, capacity, now); saveFunnelState(key, state, expireSeconds); return true; // 第一次肯定能通过 }

步骤 2：补充令牌（客户端计算）

// 计算自上次检查以来经过的时间（毫秒） long timePassedMillis = now - state.getNextLeakTime(); // 如果时间差大于 0，说明需要补充令牌 if (timePassedMillis > Constant.ZERO) { // 计算应该补充的令牌数：时间差（毫秒）* 漏出速率 / 1000 int tokensToAdd = (int) ((timePassedMillis * state.getLeakRate()) / 1000L); // 更新剩余容量，但不能超过最大容量 int newLeftCapacity = Math.min(state.getCapacity(), state.getLeftCapacity() + tokensToAdd); state.setLeftCapacity(newLeftCapacity); // 更新下次漏出时间 state.setNextLeakTime(now); // 保存更新后的状态到 Redis saveFunnelState(key, state, expireSeconds); }
📊 令牌补充计算示例：
  • 假设漏出速率为 10 个/秒
  • 距离上次检查已过去 500 毫秒
  • 应补充令牌数 = (500 * 10) / 1000 = 5 个
  • 如果当前剩余容量为 3，最大容量为 20
  • 更新后剩余容量 = min(20, 3 + 5) = 8

步骤 3：判断并消耗令牌

// 判断是否允许请求 if (state.getLeftCapacity() <= Constant.ZERO) { // 没有可用令牌，拒绝请求 return false; } // 有可用令牌，消耗一个令牌 state.setLeftCapacity(state.getLeftCapacity() - Constant.ONE); // 保存更新后的状态到 Redis saveFunnelState(key, state, expireSeconds); // 允许请求通过 return true;

5. 相关方法

5.1 getFunnelState - 获取漏斗状态

从 Redis 中获取漏斗状态信息。

/** * 从 Redis 中获取漏斗状态 */ private FunnelState getFunnelState(String key) { // 从 Redis Hash 中批量获取漏斗状态的各个字段 List<Object> objects = lockRedisTemplate.opsForHash().multiGet(key, FUNNEL_STATE_HAS_KEYS); // 检查数据是否完整 if (CollectionUtils.isEmpty(objects) || objects.size() != FUNNEL_STATE_HAS_KEYS.size()) { return null; } // 构建字段映射 Map<String, Object> entries = new HashMap<>(Constant.DEFAULT_MAP_SIZE); for (int i = Constant.ZERO, size = FUNNEL_STATE_HAS_KEYS.size(); i < size; i++) { Object o = objects.get(i); if (Objects.isNull(o)) { continue; } entries.put((String) FUNNEL_STATE_HAS_KEYS.get(i), objects.get(i)); } // 提取各个字段并构建 FunnelState 对象 Integer capacity = (Integer) entries.get(FunnelState.CAPACITY_KEY); Integer leakRate = (Integer) entries.get(FunnelState.LEAK_RATE_KEY); Integer leftCapacity = (Integer) entries.get(FunnelState.LEFT_CAPACITY_KEY); Long nextLeakTime = (Long) entries.get(FunnelState.NEXT_LEAK_TIME_KEY); return FunnelState.build(capacity, leakRate, leftCapacity, nextLeakTime); }

5.2 saveFunnelState - 保存漏斗状态

将漏斗状态保存到 Redis，使用管道操作提高性能。

/** * 将漏斗状态保存到 Redis */ private void saveFunnelState(String key, FunnelState funnelState, int expireSeconds) { lockRedisTemplate.executePipelined((RedisCallback<Void>) connection -> { // 执行多个 hash 操作（使用管道批量执行） lockRedisTemplate.opsForHash().put(key, FunnelState.CAPACITY_KEY, funnelState.getCapacity()); lockRedisTemplate.opsForHash().put(key, FunnelState.LEAK_RATE_KEY, funnelState.getLeakRate()); lockRedisTemplate.opsForHash().put(key, FunnelState.LEFT_CAPACITY_KEY, funnelState.getLeftCapacity()); lockRedisTemplate.opsForHash().put(key, FunnelState.NEXT_LEAK_TIME_KEY, funnelState.getNextLeakTime()); // 设置过期时间 lockRedisTemplate.expire(key, expireSeconds, TimeUnit.SECONDS); return null; }); }
