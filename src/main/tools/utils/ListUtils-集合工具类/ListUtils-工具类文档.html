ListUtils 工具类文档

包路径： com.jst.aftersale.common.utils.ListUtils

作者： 疆戟 | 日期： 2024/8/20 | 版本： 1.0

描述： ListUtils 封装了 Java Stream API 的常用操作，提供了便捷的集合处理方法，简化日常开发中的集合操作代码。

一、映射操作 (Mapping)

1.1 map - 映射转换

public static <T,R> List<R> map(List<T> list, Function<? super T, ? extends R> mapper)

功能： 将列表中的每个元素通过映射函数转换为新类型，并自动过滤 null 值

参数说明
list待映射的列表
mapper映射函数，将 T 类型转换为 R 类型

返回值： 映射后的新列表（过滤掉 null 值）

示例 1：提取对象属性
// 提取所有用户的姓名
List<User> users = Arrays.asList(
    new User(1L, "张三", "销售部"),
    new User(2L, "李四", "市场部")
);
List<String> names = ListUtils.map(users, User::getName);
// 结果: ["张三", "李四"]

// 提取用户ID
List<Long> userIds = ListUtils.map(users, User::getId);
// 结果: [1L, 2L]
示例 2：数学运算
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> squares = ListUtils.map(numbers, n -> n * n);
// 结果: [1, 4, 9, 16, 25]

// 计算每个订单的总金额
List<Order> orders = ...;
List<BigDecimal> totals = ListUtils.map(orders, Order::getTotalAmount);

1.2 mapDistinct - 映射并去重

public static <T,R> List<R> mapDistinct(List<T> list, Function<? super T, ? extends R> mapper)

功能： 映射并去除重复元素

示例：获取唯一的部门列表
List<User>oting = Arrays.asList(
    new User("张三", "销售部"),
    new User("李四", "销售部"),
    new User("王五", "市场部"),
    new User("赵六", "技术部")
);
List<String> departments = ListUtils.mapDistinct(users, User::getDepartment);
// 结果: ["销售部", "市场部", "技术部"] (去除了重复的"销售部")

1.3 mapToSet - 映射为 Set

public static <T,R> Set<R> mapToSet(List<T> bul, Function<? super T, ? extends R> mapper)

功能： 映射为 Set 集合（自动去重）

示例：获取所有不同的城市
List<Address> addresses = Arrays.asList(
    new Address("北京"),
    new Address("上海"),
    new Address("北京"),
    new Address("广州")
);
Set<String> cities = ListUtils.mapToSet(addresses, Address::getCity);
// 结果: {"北京", "上海", "广州"} (Set 自动去重)

1.4 mapBuild - 连续映射

public static <T,R,E> List<E> mapBuild(List<T> list, Function<? super T, ? extends R> mapper, Function<? super R,? extends E> buildMapper)

功能： 进行两次连续的映射转换

示例：用户 -> 姓名 -> 带前缀的姓名
List<User> users = ...;
List<String> results = ListUtils.mapBuild(
    users,
    User::getName,        // 第一次映射：User -> String
    name -> "用户：" + name  // 第二次映射：String -> String
);
// 结果: ["用户：张三", "用户：李四", ...]

二、过滤操作 (Filtering)

2.1 filter - 过滤

public static <T> List<T> filter(List<T> list, Predicate<? super T> predicate)

功能： 根据条件过滤元素

示例 1：按年龄过滤
List<User> users = Arrays.asList(
    new User("张三", 25),
    new User("李四", 17),
    new User("王五", 30)
);
List<User> adults = ListUtils.filter(users, user -> user.getAge() >= 18);
// 结果: [张三(25), 王五(30)]
示例 2：按状态过滤
<三分>List<Product> products = ...; List<Product> available = ListUtils.filter(products, Product::isAvailable); List<Product> active = ListUtils.filter(products, p -> p.getStatus() == ProductStatus.ACTIVE);
注意： 也提供了对 Set 的过滤版本

2.2 filterMap - 过滤并映射

public static <T,R> List<R> filterMap(List<T> list, Predicate<? super T> filter, Function<? super T, ? extends R>nimapper)

功能： 先过滤符合条件的元素，再进行映射转换

示例：获取所有成年用户的姓名
List<User> users = ...;
List<String> adultNames = ListUtils.filterMap(
    users,
    user -> user.getAge() >= 18,  // 过滤：成年用户
    User::getName                 // 映射：提取姓名
);
// 结果: ["张三", "王五"]
示例：获取高价值订单的订单号
List<Order> orders = ...;
List<String> orderIds = ListUtils.filterMap(
    orders,
    order -> order.getAmount().compareTo(BigDecimal.valueOf(1000)) > 0,  // 过滤
    Order::getOrderId                                                    // 映射
);

public static <T, K, V> Map<K, V> filterToMap(List<T> list, Predicate<? super T> filter, Function<? super T, ? extends K> keyMapper, Function<? super T, ? extends V> valueMapper)

功能： 过滤后将符合条件的元素转为 Map

示例：将活跃用户转为 Map
List<User> users = ...;
Map<Long, String> activeUserMap = ListUtils.filterToMap(
    users,
    User::isActive,     // 过滤：只保留活跃用户
    User::getId,        // 键：用户ID
    User::getName       // 值：用户名
);
// 结果: {1L: "张三", 3L: "王五"}

三、转换操作 (Transformation)

3.1 toMap - 转为 Map

版本 1：对象本身作为值

public static <T, K> Map<K, T> toMap(List<T> list, Function<? super T, ? extends K> keyMapper)
List<User> users = ...;
Map<Long, User> userMap = ListUtils.toMap(users, User::getId);
// 结果: {1L: User对象1, 2L: User对象2}

版本 2：指定键和值

public static <T, K, V> Map<K, V> toMap(List<T> list, Function<? super T, ? extends K> keyMapper, Function<? super T, ? extends V> valueMapper)
// ID -> 姓名
Map<Long, String> nameMap = ListUtils.toMap(users, User::getId, User::getName);
// 结果: {1L: "张三", 2L: "李四"}

// 订单号 -> 总金额
Map<String, BigDecimal> amountMap = ListUtils.toMap(orders, Order::getOrderId, Order::getAmount);

版本 3：指定合并策略

public static <T, K, V> Map<K, V> toMap(List<T> list, Function<? super T, ? extends K> keyMapper, Function<? super T, ? extends V> valueMapper, BinaryOperator<V> mergeFunction)
示例：相同类别数量求和
List<Item> items = Arrays.asList(
    new Item("电器", 10),
    new Item("电器", 20),
    new Item("服装", 15)
);
Map<String, Integer> totalMap = ListUtils.toMap(
    items,
    Item::getCategory,
    Item::getQuantity,
    Integer::sum  // 重复键时求和
);
// 结果: {"电器": 30, "服装": 15}

四、分组操作 (Grouping)

4.1 groupingBy - 分组

版本 1：按键分组

public static <K,V> Map<K, List<V>> groupingBy(List<V> list, Function<? super V, ? extends K> keyMapper)
示例：按部门分组员工
List<Employee> employees = Arrays.asList(
    new Employee("张三", "销售部"),
    new Employee("李四", "销售部"),
    new Employee("王五", "市场部")
);
Map<String, List<Employee>> deptMap = ListUtils.groupingBy(employees, Employee::getDepartment);
// 结果: {"销售部": [张三, 李四], "市场部": [王五]}

版本 2：分组并映射值public static <K,V,U> Map<K, List<U>> groupingBy(List<V> list, Function<? super V, ? extends K> keyMapper, Function<V, U> mapper)

// 按部门分组，只保留员工姓名
Map<String, List<String>> deptNameMap = ListUtils.groupingBy(
    employees,
    Employee::getDepartment,
    Employee::getName
);
// 结果: {"销售部": ["张三", "李四"], "市场部": ["王五"]}

版本 3：分组并转换为 Set

public static <K,V,U> Map<.ToString, Set<U>> groupingByReturnSet(List<V> list, Function<? super V, ? extends K> keyMapper, Function<V, U> mapper)
// 按地区分组，使用 Set 自动去重
Map<String, Set<String>> cityMap = ListUtils.groupingByReturnSet(
    orders,
    Order::getRegion,
    Order::getCity
);

五、展平操作 (FlatMap)

5.1 flatMapDistinct - 展平并去重

public static <T,R> List<R> flatMapDistinct(List<T> list, Function<? super T, ? extends Stream<? extends R>> mapper)

功能： 将嵌套的集合展平为一维列表，并去重

示例 1：展平订单中的所有商品
List<Order> orders = Arrays.asList(
    new Order(Arrays.asList(product1, product2)),
    new Order(Arrays.asList(product2, product3))
);
List<Product> allProducts = ListUtils.flatMapDistinct(
    orders,
    Order::getProducts  // 返回 List<Product>.stream()
);
// 结果: [product1, product2, product3] (去重)
示例 2：获取所有用户的角色
List<User> users = ...;
List<String> allRoles = ListUtils.flatMapDistinct(
    users,
    user -> user.getRoles().stream()
);

六、集合运算 (Collection Operations)

6.1 subtract - 差集

public static <T> List<T> subtract(List<T> sourceData, Collection<T> comparisonData)

功能： 返回源数据中存在但对照数据中不存在的元素

示例 1：计算剩余任务
List<Integer> all = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> processed = Arrays.asList(1, 3, 5);
List<Integer> remaining = ListUtils.subtract(all, processed);
// 结果: [2, 4]
示例 2：找出未处理的订单
List<Order> allOrders = ...;
List<Order> processedOrders = ...;
List<Order> unprocessed = ListUtils.subtract(allOrders, processedOrders);

6.2 partition - 拆分

public static <T> List<List<T>> partition(List<T> list, int size)

功能： 将列表拆分为指定大小的子列表

示例 1：拆分为固定大小
List<Integer> list = Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8, 9);
List<List<Integer>> partitions = ListUtils.partition(list, 3);
// 结果: [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
示例 2：分批处理订单
List<Order> orders = ...;
List<List<Order>> batches = ListUtils.partition(orders, 100);
for (List<Order> batch : batches) {
    processBatch(batch);  // 每次处理 100 个订单
}

七、其他工具方法 (Utility)

7.1 joining - 连接

public static <T> String joining(List<T> list, Function<? super T, ? extends String> mapper)

功能： 用分号将元素连接成字符串

示例 1：连接用户名
List<User> users = ...;
String names = ListUtils.joining(users, User::getName);
// 结果: "张三;李四;王五"
示例 2：连接ID列表

String idStr = ListUtils.joining(ids, String::valueOf);

注意： 分隔符固定为分号（;）

7.2 getFirst - 获取第一个元素

public static <T> T getFirst(List<T> list, T defaultValue)

功能： 安全获取第一个元素，列表为空时返回默认值

示例：安全获取用户
List<User> users = ...;
User firstUser = ListUtils.getFirst(users, null);
String firstName = ListUtils.getFirst(names, "");
Integer firstId = ListUtils.getFirst(ids, 0);

7.3 ofNullable - 空值安全

版本 1：返回列表

public static <T> List<T> ofNullable(List<T> source, List<T> defaultValue)
List<String> result = ListUtils.ofNullable(maybeEmpty, Collections.emptyList());

版本 2：返回 Stream

public static <T> Stream<T> ofNullable(List<T> source, Stream<T> defaultValue)
队长<User> userStream = ListUtils.ofNullable(users, Stream.empty());

注意事项与最佳实践

⚠️ 重要提醒

  • 所有方法对 null 输入都有会有良好的处理，不会抛出 NullPointerException
  • joining 方法使用分号（;）作为分隔符
  • 所有返回集合的方法，输入为 null 时返回空集合而不是 null
  • toMap 方法在键重复时会使用合并策略（默认保留第一个值）

💡 使用建议

  • 优先使用这些工具方法而不是直接使用 Stream API，代码更简洁易读
  • 方法自动处理 null 值，减少防御性编程代码
  • 对于复杂逻辑，建议拆分为多个步骤以提高可读性
  • 大量数据处理时，注意考虑性能和内存使用
